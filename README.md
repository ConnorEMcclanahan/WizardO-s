## Requirements

- Unreal Engine 5.8

## Opening the project

1. Clone the repository.
2. Open `WizardOs.uproject` with Unreal Engine 5.8.
3. If prompted, rebuild the project modules.

## Repository contents

Source-controlled project files include `Config/`, `Content/`, `Source/`, and `WizardOs.uproject`. Generated Unreal directories such as `Binaries/`, `DerivedDataCache/`, `Intermediate/`, and `Saved/` are excluded.
